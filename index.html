💡 How Decryption Works

DES decryption uses the exact same algorithm as encryption — the only difference is that the 16 round subkeys are applied in reverse order (K₁₆ first, K₁ last). This is the elegance of the Feistel network: one circuit serves both directions.

Encrypt: K₁ → K₂ → … → K₁₆ | Decrypt: K₁₆ → K₁₅ → … → K₁

About DES

Interactive DES Encryption & Decryption Visualizer — An educational tool for learning cryptography. Built with HTML, CSS & Vanilla JavaScript.

DES is defined in FIPS 46-3. For modern encryption use AES-256.
